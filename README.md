# Task 14 - JavaScript Loops

## Description
A small browser project that uses JavaScript loops and conditionals to
perform several operations on a given number.

## Operations performed
- Sum of the first `n` natural numbers.
- Multiplication table of `n`.
- Prime number check.
- Finding all factors of `n`.
- Sum of all digits of `n`.
- Armstrong number check (sum of cubes of the digits).

## Files
- `index.html` - page structure (CSS and JS linked).
- `style.css` - styling for the page.
- `script.js` - all the loop-based logic.
- `README.md` - this file.

## How to run
1. Open `index.html` in any modern browser.
2. Open the Developer Tools and switch to the Console tab.
3. Click the **Run Program** button.
4. Results are printed with `console.log` and also shown on the page.

## Test variables
The program checks the following variables:
`num1 = 153`, `num2 = 5`, `num3 = 7`, `num4 = 12`, `num5 = 370`,
`num6 = 9`, `num7 = 28`.
